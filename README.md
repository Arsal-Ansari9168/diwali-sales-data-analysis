# 🪔 Diwali Sales Data Analysis

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on Diwali sales data using Python.

The main purpose of this project is to analyze customer purchasing behavior and sales patterns based on gender, age group, state, marital status, occupation, product category, and product ID.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 📂 Dataset

The dataset contains Diwali sales information such as:

- Customer details
- Gender
- Age and Age Group
- Marital Status
- State
- Occupation
- Product Category
- Product ID
- Number of Orders
- Purchase Amount

## 🧹 Data Cleaning

The following steps were performed:

- Removed unnecessary columns such as `Status` and `unnamed1`
- Checked missing values
- Removed rows containing missing values
- Converted the `Amount` column into integer data type
- Checked dataset structure and statistical information

## 📊 Analysis Performed

### 1. Gender Analysis
Analyzed customer count and total sales based on gender.

### 2. Age Group Analysis
Analyzed customer distribution and total sales across different age groups.

### 3. State-wise Analysis
Identified the top 10 states based on total sales amount.

### 4. Marital Status Analysis
Analyzed sales based on marital status and gender.

### 5. Occupation Analysis
Analyzed customer count and sales across different occupations.

### 6. Product Category Analysis
Analyzed product categories based on sales and order distribution.

### 7. Top 10 Products
Identified the top 10 products based on the number of orders.

## 📈 Visualizations

The project includes:

- Gender-wise customer count
- Gender-wise sales
- Age group-wise sales
- Top 10 states by sales
- Marital status and gender-wise sales
- Occupation-wise sales
- Product category-wise sales
- Top 10 most ordered products

## 💡 Key Insights

- The dataset was cleaned by removing unnecessary columns and missing records.
- Female customers have a higher number of records than male customers.
- The 26–35 age group contributes significantly to total sales.
- State-wise analysis shows differences in sales across regions.
- Food is one of the major product categories by sales.
- The project also identifies the products with the highest number of orders.

## 🎯 Conclusion

This project demonstrates how Python can be used for data cleaning, exploratory data analysis, and data visualization.

Pandas was used for data manipulation and analysis, while Matplotlib and Seaborn were used to create visualizations and understand sales patterns.
